# IDK Visual Lab

A standalone Android Compose demo. Animated objects and display settings are generated and rendered entirely inside this app.

## Build
Requires JDK 17, Android SDK platform 36, and Gradle 8.11.1.

```bash
gradle :app:assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions can build it from the Actions tab using **Build Android APK** → **Run workflow**.
